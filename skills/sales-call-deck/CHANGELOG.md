# Changelog — sales-call-deck

## 1.0.0 — 2026-11-19

- First public version.
- Turns a discovery-call transcript and a commercial proposal into a self-contained HTML deck with a presenter view (P key): per-slide notes with the prospect's timestamped quotes, questions to ask, an always-visible objection cheat sheet.
- References: closing method, narrative arc, design review.
- Scripts: image extraction from the proposal PDF, single-file build, headless-Chrome screenshots with contact sheets.
- Fictional example deck (`examples/exemple-slides.js`).
